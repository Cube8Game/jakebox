# Jakebox

Jakebox is a game engine where you can make multiplayer (or singleplayer) text-based games that run on the browser. Right now, Jakebox is in active development so many features are not available yet.

## Planned Features

- [X]  Web GUI
- [X]  Lua scripting
- [X]  Official hosting
- [X]  Official games
- [ ]  Styling/CSS
- [ ]  Unofficial game search

## How to use

Go to [jakebox.tunnl.gg](https://jakebox.tunnl.gg) to play the latest tagged release of the game.
Go to [box.jakewhibley.org](https://box.jakewhibley.org) to play the latest stable version of the game.
